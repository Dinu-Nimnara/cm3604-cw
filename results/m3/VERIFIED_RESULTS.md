# Member 3 verified development results

These files record already-completed Windows CPU runs supplied in the terminal
transcripts. They were not generated by a new inference run, and do not contain
invented per-fact predictions or probabilities.

Model: `MoritzLaurer/DeBERTa-v3-base-mnli-fever-anli`.
Published implementation reference: Member 3 commit
`3b98fd87695257ab49bcf3a594aeeac8cbd55a05`.

## Dataset and evaluation

The supplied development data contains 221 evaluated facts: 112 Supported and
109 Not Supported, including IR examples mapped to NS by the coursework driver.
The two input paths are `data/dev_labeled_ChatGPT.jsonl` and
`data/passages_bm25_ChatGPT_humfacts.jsonl`.

The classifier predicts S when the maximum entailment probability across the
evaluated evidence is greater than or equal to the threshold, otherwise NS.
The selected threshold was tuned on the supplied development set. Therefore,
these are development results, not independent held-out test results.

## Environment and command

Reported environment: Python 3.10.11, PyTorch 2.5.0+cpu, CPU execution, and the
coursework's pinned package requirements. CUDA was unavailable in this setup.
No GPU-performance claim is made.

```powershell
.\.venv\Scripts\python.exe factchecking_main.py --mode entailment
```

## Files and provenance

- `evaluation.json`: machine-readable metrics, thresholds, confusion matrices,
  and SHA-256 hashes of the source transcripts.
- `metrics.csv`: the baseline and selected-setting summary as a CSV table.
- `entailment_cpu_console.txt`: selected-setting console excerpts.
- `baseline_cpu_console.txt`: baseline console excerpts.

The console files preserve selected output lines, including the final confusion
matrix and metrics. Local filesystem prompts, the full list of dataset claims,
and download messages are omitted. These are labelled excerpts, not full raw
execution logs. All recorded metrics were checked against the confusion matrices
and reported console values.

Source transcripts uploaded by the evaluator:

- Baseline: `Pasted text(20261105-205338).txt`.
- Selected: `Pasted text(20261106-053503).txt`.

The original driver prints aggregate statistics but does not save per-fact
probabilities. Those probabilities cannot be reconstructed from these console
transcripts. To collect scores and errors from a fresh local evaluation, run the
separate supporting tool, for example:

```powershell
.\.venv\Scripts\python.exe tune_member3.py --cache results/m3/member3_scores.json --report results/m3/tuning_report.json
```

That command performs model inference for uncached facts. With a complete cache,
`--scores-only` evaluates thresholds without running the model again. It is not
necessary to rerun inference just to preserve the aggregate results recorded here.
